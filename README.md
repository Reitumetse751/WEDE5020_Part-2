Project Overview
The Book Nook is a local independent bookstore based in Cape Town, South Africa. The store was established in 2012 and has become a beloved community hub for readers of all ages. This website project aims to create a functional and visually appealing online presence for The Book Nook.

The website consists of five core pages that provide visitors with information about the store, its products, upcoming events, and contact details. The website is designed to be easy to navigate, informative, and engaging for all users.

Part 2 Overview
Part 2 focused on designing the visuals of the website using CSS. This included creating an external stylesheet, applying typography, building layout structures, adding visual styles, and implementing responsive design for different screen sizes.
